# Open protocol, commercial experience

Date: 2026-09-07  
Status: seed

## 起因

如果 Cognitive Mirror 的价值依赖一个“秘密 Prompt”，它很容易被复制，也和项目本身强调可审计、可质疑的精神冲突。

另一方面，真正长期有价值的体验可能来自：连续历史、来源追踪、Reality Loop、隐私、安全、导入与检索，而不是那段 Prompt 本身。

## 当前想法

更自然的边界可能是：

> **Open epistemics, commercial experience.**

也就是：

- Prompt 可以公开；
- 认识论原则可以公开；
- evals 可以公开；
- 方法如何演化可以公开；
- 未来商业产品则为普通用户提供长期、安全、连续、无需 GitHub 的体验。

公开协议不是“免费阉割版”，而应该真的有用。

商业产品必须靠额外价值成立，而不是靠隐藏方法。

## 可能的商业含义

免费路径可以是：

```text
public protocol
      ↓
用户自己的 AI
      ↓
可选 private state repo
```

商业产品未来如果成立，应该主要解决：

- 无需 GitHub 的自然体验；
- 安全的长期个人状态；
- 高质量检索与 lineage；
- 数据导入、导出与删除；
- 多端体验；
- 模型可替换但语义不漂；
- 隐私与信任。

## 还不知道

- 用户是否愿意为 longitudinal continuity 付费？
- 免费 GitHub Harness 会不会已经满足大部分高阶用户？
- 哪种定价方式最不容易诱导产品追求聊天时长和“洞见数量”？

商业化不是当前要解决的问题；当前仍应先验证真实使用价值。
