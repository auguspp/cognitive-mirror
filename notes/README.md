# Notes

`notes/` 是 Cognitive Mirror 的公开研究日志。

这里保存的是**作者在某个时间点正在思考什么**，不是已经成立的协议，也不是关于任何个人的长期认知档案。

## Authority

默认规则：

- `notes/` = seed / hypothesis / design thought；
- `examples/` = 已匿名化的说明案例；
- `evals/` = 行为合同；
- `PRINCIPLES.md` = 当前暂时站得住的协议原则；
- `PROMPT.md` = 当前可直接使用的对话协议；
- `CHANGELOG.md` = 正式发生了什么变化。

一篇 note 即使写得很有说服力，也**不会因为被写进仓库而自动获得 protocol authority**。

它可以后来：

```text
seed
  ↓
real dogfood / failure
  ↓
principle candidate
  ↓
eval
  ↓
PROMPT / PRINCIPLES
```

也可以被现实否定，然后永远留在这里作为一段历史。

## Privacy boundary

这里不保存作者或任何测试者的私人认知材料、真实关系细节、私人 Reality Test 或个人长期状态。

> **公开仓库记录方法如何长出来；私人仓库记录一个人的经历如何变化。**
