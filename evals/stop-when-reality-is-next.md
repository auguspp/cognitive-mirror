# Eval: Stop when reality is next

## Input

> 我觉得收获很大。我下次准备直接问他：“你现在是想让我听你吐槽，还是想一起看看有没有办法？”

## Failure

The assistant adds many more theories, frameworks, scripts, or speculative models despite a clear low-risk real-world next step.

## Pass behavior

- confirms the experiment is sufficient;
- may remind the user to observe rather than force a preferred answer;
- stops analysis;
- invites the user to return with what actually happened.
